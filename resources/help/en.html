PuTTYgen Help

PuTTYgen generates, inspects and converts SSH private keys using the PuTTY 0.85 key engine.

Generating a key

  1. Select RSA, DSA, ECDSA, EdDSA or SSH-1 RSA in Parameters.
  2. Enter the bit count for RSA, DSA or SSH-1 RSA. Select nistp256, nistp384 or nistp521 for ECDSA, or Ed25519/Ed448 for EdDSA. RSA/DSA lengths below 256 prompt to reset to 2048; lengths below 2048 require confirmation.
  3. Click Generate and move the mouse over the window until entropy collection completes. The operating system's secure random source and mouse data feed the original random engine. Generation progress then appears.
  4. Edit the comment, enter and confirm a passphrase, and save the private key. Saving without a passphrase requires confirmation.

The Key menu offers probable primes, proven primes, and proven primes with an even distribution. It also offers strong RSA primes. These options apply to the next generation.

Loading and importing

Click Load or choose File → Load private key. The file content determines its type. Encrypted keys prompt for a passphrase; an incorrect passphrase can be retried or cancelled. Failed or cancelled loading preserves the current key. Conversions → Import key loads foreign formats without the conversion notice shown by Load. Supported inputs include PuTTY PPK, SSH-1, applicable OpenSSH formats, and ssh.com.

Public keys, fingerprints and comments

The public key box provides text for authorized_keys and supports selection and copying. Editing the comment updates this text. Select SHA256 or MD5 under Key → Fingerprint type; SSH-1 uses its original fingerprint representation. Save public key writes SSH-2 keys in RFC 4716 format, which differs from the text displayed for pasting.

Saving and converting

Save private key writes PuTTY PPK for SSH-2, or the original SSH-1 format. Conversions offers OpenSSH automatic format, OpenSSH with forced new format, and ssh.com exports. Unavailable formats are disabled for the current key. Private key saving checks both passphrases before choosing a file. Existing files require overwrite confirmation. File errors include expandable details.

Private key file parameters

Key → Parameters for saving key files selects PPK version 2 or 3. PPK 3 offers Argon2id, Argon2i and Argon2d, memory in KiB, a time target in milliseconds with automatic passes or a fixed pass count, and parallelism. PPK 2 does not use Argon2. Cancel keeps the previous settings. PuTTY validates these parameters again when saving. Automatic pass counts depend on machine speed.

SSH certificates

With a suitable SSH-2 private key loaded, choose Key → Add certificate and select a matching OpenSSH certificate public key. An invalid or mismatched certificate leaves the current key intact. A certified key displays a certificate summary in place of the public key box; Certificate info opens the complete details. Remove certificate restores the base key. Save and export availability follows the selected format's capabilities.

Language and closing

The Language menu switches between Simplified Chinese and English and remembers the selection. Changing language preserves the current key and unsaved comment and passphrase edits. The first launch defaults to Chinese. Closing during a key operation waits for completion and securely releases the key; the window remains responsive while waiting.

About and licences

Help → About shows application, PuTTY and Qt versions, with controls to view the original PuTTY licence or visit its official website. This help is available offline. Installation packages also include Qt and other third-party licence material.
