PuTTYgen 使用帮助

PuTTYgen 用于生成、查看和转换 SSH 私钥。密钥处理核心来自 PuTTY 0.85。

生成密钥

  1. 在“参数”区域选择 RSA、DSA、ECDSA、EdDSA 或 SSH-1 RSA。
  2. RSA、DSA 和 SSH-1 RSA 填写位数；ECDSA 选择 nistp256、nistp384 或 nistp521；EdDSA 选择 Ed25519 或 Ed448。小于 256 位的 RSA/DSA 将提示恢复为 2048 位；小于 2048 位会提示确认。
  3. 点击“生成”，在窗口空白区域移动鼠标，进度达到收集要求后开始生成。系统安全随机源与鼠标数据一起用于原版随机核心。
  4. 填写密钥注释和口令，在确认框重复口令，再保存私钥。没有口令的私钥不会加密，保存时需要确认。

“密钥”菜单提供概率素数、已证明素数和均匀分布的已证明素数策略，以及 RSA 强素数选项。这些设置用于下一次生成。

加载与导入

点击“加载”或“文件 → 加载私钥”。文件类型按内容识别。加密私钥需要输入口令，错误口令可以重试或取消；失败和取消保留当前密钥。“转换 → 导入密钥”也可以加载外部格式；“加载”成功读取外部格式后会提示将其另存为 PuTTY 格式。支持 PuTTY PPK、SSH-1 私钥、适用的 OpenSSH 格式和 ssh.com 格式。

公钥、指纹和注释

公钥框显示可粘贴至 authorized_keys 的文本，可选择并复制。编辑注释会更新公钥。指纹可在“密钥 → 指纹类型”中切换 SHA256/MD5；SSH-1 使用原版对应指纹。选择“保存公钥”时，SSH-2 公钥保存为 RFC 4716 格式，与主窗粘贴用文本不同。

保存与转换

“保存私钥”使用 PuTTY PPK（SSH-2）或 SSH-1 格式。“转换”菜单可导出 OpenSSH 自动格式、强制新格式或 ssh.com 私钥，不适用的入口会禁用。导出前检查两次口令；不一致会阻止保存。选择文件后，已有文件需要确认覆盖。读写失败显示错误和可展开的详细信息。

私钥文件参数

“密钥 → 保存密钥文件参数”可以选择 PPK 版本 2/3。PPK 3 提供 Argon2id、Argon2i、Argon2d，以及内存（KiB）、自动计算轮数的时间（毫秒）或固定轮数、并行度。PPK 2 不使用 Argon2。取消对话框保留原设置。保存时由 PuTTY 核心再次验证参数；自动模式的实际轮数随机器速度改变。

SSH 证书

加载适用的 SSH-2 私钥后，使用“密钥 → 添加证书”选择匹配的 OpenSSH 证书公钥。只有证书与当前私钥匹配才能添加；失败保留现有密钥。带证书时，主窗显示证书摘要，“证书信息”显示完整信息。可用“移除证书”恢复基础密钥。保存与导出遵循相应格式的能力。

语言和退出

“语言”菜单切换简体中文和 English。程序记住语言选择，切换保留当前密钥及尚未保存的注释和口令。首次启动使用中文。生成或文件处理过程中关闭窗口会等待该操作完成再释放密钥；等待期间窗口继续响应。

关于与许可证

“帮助 → 关于”显示程序、PuTTY 核心和 Qt 版本，可查看 PuTTY 许可证原文或打开官方网站。此帮助无需联网即可阅读。Qt 与其他第三方的许可材料随安装包提供。
