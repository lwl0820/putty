# Windows 自动与桌面验收安排

用户于 2026-10-15 明确选择“使用仓库的 Windows CI，桌面操作由我验收”。这已授权接入本仓库自动构建和测试，不再将 Windows 开发机连接作为必要前提。

自动验证使用仓库现有 MSVC 2022 x64、锁定 Qt 6.8.3 工具路线。新增套件工作流与既有 PuTTYgen 工作流分开，保护正在使用的发布/Arch 流程。先覆盖共享核心与三个 CLI，再逐步纳入可运行的两个 Qt 产品。测试报告必须列出执行、失败和跳过的具体项目；配置成功或工作流文件落地均不表示 CI 已实际运行。

注册表、随机种子和代理测试继续遵守父设计：进程级 hive 覆盖不能假定自动继承给子进程；原版及自有子进程逐个验证。允许使用专用临时 CI 测试身份，但不能把任何普通本机 Windows 用户当作可写测试环境。所有可定位的测试材料与报告收集根仍为项目 `.tmp/`。

CI 的 Windows Server runner 结果只证明该 runner 的自动行为，不替代 Windows 10 1809+/11 的真实桌面。两版目标桌面的启动、字体/DPI、输入法、剪贴板、托盘、无托盘、窗口行为和权限交互由用户人工验收，主会话交付具体程序与操作清单后记录结果。
