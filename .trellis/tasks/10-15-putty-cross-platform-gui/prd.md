# PuTTYgen Windows/Linux 跨平台 GUI

## 目标与用户价值

为 PuTTYgen 提供 Windows/Linux 桌面 GUI，解决 Linux 版缺少 Windows 原版图形操作的问题。用户可在两平台沿用原版操作习惯，通过图形界面完成全部原版 GUI 密钥操作。

## 背景与证据

用户指定的参考项目为 [github/putty](https://github.com/github/putty)，该镜像于 2023-10-20 归档。官方手册将 Unix 的 `puttygen` 列为命令行工具；Windows 版具有独立 GUI。已经下载官方 PuTTY 0.85 发布归档进行只读研究，并与官方 SHA256 校验清单比对一致。

本地原先只有 Trellis 初始化配置，尚无产品源码或构建工程。上游 `windows/CMakeLists.txt:137`、`unix/CMakeLists.txt:90` 与 `:99` 说明两平台入口不同，但共享密钥与密码处理模块。具体证据和文件锚点保存在 `research/upstream.md`；全部原版 GUI 对照项保存在 `research/gui-parity.md`。

## 需求与约束

| 编号 | 需求 |
| --- | --- |
| R1 | 支持 Windows 10（1809 及以后）/11 x64、Ubuntu 22.04/24.04 x64，以及用户追加的 Arch Linux 滚动版 x86_64；Linux 同时验证 X11 与 Wayland 桌面。 |
| R2 | 完整覆盖固定基线 Windows 原版 PuTTYgen 的 GUI 功能，尽量保留操作逻辑；不删减高级菜单、旧算法、证书或格式选项。平台字体、窗口装饰及文件对话框允许有视觉差异。 |
| R3 | 本期不支持、不验证 macOS；用户暂时没有 macOS 环境。 |
| R4 | 保留用户指定项目的来源关系；实现与验收采用官方 PuTTY 0.85，记录来源、固定版本、完整性校验与本地适配改动。 |
| R5 | 会话、文档和新增注释使用中文；上游源码及许可证的既有文本原样保留。 |
| R6 | 产品界面不得展示开发需求、任务说明、验证清单或实现过程相关文字。 |
| R7 | 开发所需临时文件使用项目工作目录的 `.tmp/`，不使用系统临时目录。 |
| R8 | 首版只移植 PuTTYgen，其他 PuTTY 套件工具不纳入本期。 |
| R9 | 中英双语，首次启动默认中文；可切换英文并记住选择，切换时保留当前密钥与编辑状态。菜单、控件和应用提示支持两种语言；原始许可证和诊断详情保留原文。 |
| R10 | 普通用户可直接启动发布后的 GUI，无需自行安装开发工具；提供 Windows ZIP 便携包、分别适用于 Ubuntu 22.04/24.04 的 DEB，以及 Arch Linux 的 `.pkg.tar.zst` 包。Arch 包通过 pacman 安装系统运行依赖并提供桌面入口，Actions 上传包、SHA256 和验证报告。 |
| R11 | 仓库是 PuTTY 套件项目，PuTTYgen 作为独立组件组织在 `apps/puttygen/`；共享上游、Qt 工具和顶层构建入口放公共目录。后续组件有明确扩展位置，本期不新增其他工具实现。 |

## 功能范围

| 功能 | 原版操作与覆盖边界 | 对照项 |
| --- | --- | --- |
| 主窗口与菜单 | 密钥、操作、参数分区，文件/密钥/转换/帮助菜单，助记键与键盘导航，各状态下的入口可用条件。 | G01、G13 |
| 生成密钥 | RSA、DSA、ECDSA、EdDSA、SSH-1 RSA，位数/曲线，鼠标收集熵与进度反馈。 | G02、G03 |
| 素数策略 | 三种素数生成策略、RSA 强素数开关，按原版适用条件生效。 | G04、G05 |
| 加载、查看、修改 | 加载私钥和口令输入，公钥文本及指纹，SHA256/MD5 切换，注释和口令编辑。 | G06、G07、G08 |
| 保存 | 保存公私钥，PPK v2/v3、Argon2id/i/d、内存、自动时间/固定轮数和并行度设置。 | G09、G10 |
| 格式转换 | 原版支持的外部格式导入；OpenSSH 自动格式、强制新格式与 ssh.com 导出，保留算法/格式适用限制。 | G11 |
| 证书 | 添加、移除、匹配校验、信息查看；带证书时按原版切换公钥展示区域。 | G12 |
| 辅助操作 | 关于、许可证查看、官网入口、离线帮助，所有原版警告、错误、取消与覆盖确认流程。 | G14、G15 |

| AC4 | 原版源码、归档 SHA256、固定版本、许可材料和本地改动可追溯；关于窗口可识别上游基线。 | R4 |
| AC5 | 新增文档和注释符合中文要求；两种语言下都无开发需求及任务说明进入产品界面。 | R5、R6 |

| AC8 | 首次启动中文；切换和重启后保持语言选择；已有密钥、注释和未提交输入不会因切换丢失；两种语言的布局与键盘操作可用。 | R9 |

| AC10 | 生成和高成本口令处理期间 GUI 可响应；不可重复提交相互冲突的任务；关闭、失败和对象销毁不会访问已释放的密钥或控件。 | R2 |
| AC11 | 顶层项目名为 PuTTY，组件代码、资源、测试和发布配置集中于 `apps/puttygen/`；顶层 CMake 可选择启用 PuTTYgen，共享依赖不复制到组件；使用现有 GitHub 远端安排 Actions。 | R11 |

## 不在本期范围

- PuTTY 主终端、Pageant、PSCP、PSFTP、Plink 的移植或新增 GUI。
- 终端连接、SSH 登录、会话管理、代理、转发与原版会话配置迁移。
- macOS、Ubuntu 和 Arch Linux 之外的发行版、32 位与 ARM64。
- AUR 提交、托管 pacman 仓库及新增 GitHub Release 自动发布；本轮 Arch 包沿用 Actions 产物下载。
- 像素级复制 Windows 外观、新增密码算法、自动更新或云端密钥管理。
- 原版全部 CLI 参数兼容；本产品围绕 GUI 使用场景验收。
